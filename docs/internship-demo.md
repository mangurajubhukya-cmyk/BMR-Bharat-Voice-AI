# Internship demo script

Start with the independent BMR Bharat Voice AI URL and sign in through Manus. Open a new conversation, choose `తెలుగు` in the voice-language selector, press the microphone button, speak a short Telugu question, stop recording, and show the editable transcript before sending it. Send the corrected transcript and point out that the answer is generated by the existing BMR conversation backend. Select a verified Telugu Timbre voice such as Suhana and press PLAY VOICE on the assistant response.

Repeat once with Hindi or Indian English to demonstrate the explicit Prisma v2.5 language path. Keep automatic voice reply disabled unless it is intentionally being demonstrated. If Gnani is unavailable, type the same question to demonstrate that normal BMR chat remains operational.

For submission evidence, capture the public HTTPS URL, the authenticated workspace, one Telugu transcript, one assistant response, one audio playback, and the health/route endpoints. Do not capture the API key, private cookies, dashboard credentials, or raw private transcripts.

The only live Gnani checks performed during recovery were one short English Prisma request and one short English Timbre request. Both returned HTTP 200; Prisma reported `prisma-v2.5`, and Timbre returned WAV audio. The dashboard balance was not independently verified because the isolated browser was not authenticated to the owner’s Gnani account.
